# UPGRADE — детейлинг-студия, Ульяновск

Лендинг детейлинг-студии UPGRADE (пр-т Туполева, 7в, +7 902 006-67-77).

Статический сайт без сборки: `index.html`, `styles.css`, `script.js`, шрифты в `fonts/`, изображения в `assets/`.

## Запуск локально

```bash
npx http-server -p 5173
```
